# 03 — Learning Roadmap

> **The full path from beginner to published researcher. Read in order.**

---

## 🗺️ The Big Picture (visual)

```
START
  ↓
00_START_HERE        ← you are here
  ↓
01_Research_Basics   ← learn how research works
  ↓
02_Math_And_Stats    ← build your math foundation
  ↓
03_Tools             ← set up Python, Git, LaTeX
  ↓
04_Data_Work         ← learn to find, clean, and prepare data
  ↓
05_Machine_Learning  ← build ML/DL models
  ↓
06_Paper_Publishing  ← write and publish
  ↓
07_My_Thesis         ← your actual MSc thesis
  ↓
DONE 🎓
```

You can do the stages in **parallel** for the first 2-3 months, but aim to finish `01` + `02` + `03` before deep-diving into `04` + `05`.

---

## 📅 Suggested 12-Month Plan (2-3 hours/day)

| Month | Focus | Goal |
|---|---|---|
| 1-2 | `01_Research_Basics` + start `02` | Read 30 papers, pick 3 topic ideas, find an advisor |
| 3-4 | `02_Math_And_Stats` + `03_Tools` | Math foundation solid, tools set up, GitHub active |
| 5-6 | `04_Data_Work` + start `05` | Find your dataset, clean it, build first baseline |
| 7-8 | `05_Machine_Learning` (core) | Train 3+ models, beat baseline, write results |
| 9-10 | `05_Machine_Learning` (advanced) + `06` | Tune, ablate, start writing paper |
| 11-12 | `06_Paper_Publishing` + `07_My_Thesis` | Submit to arXiv/conference, write thesis chapters |

---

## 🟢 Beginner Track (Month 1-3)

| Week | What To Do |
|---|---|
| 1 | Read `01_Research_Basics/01-04`. Brainstorm topics. |
| 2 | Read 5 papers using 3-pass method. Set up Zotero. |
| 3 | Start `02_Math_And_Stats/01_Linear_Algebra_Basics.md`. Watch 3Blue1Brown. |
| 4 | Do exercises from `02_Math_And_Stats`. Install Python + Jupyter. |
| 5-8 | Work through `02_Math_And_Stats/02-03`. Set up Git + GitHub. |
| 9-12 | Read `03_Tools/01-03`. Run 1 Kaggle competition. |

**Done when:** You can read a paper, run a Python script, push to GitHub, write a paragraph in LaTeX.

---

## 🟡 Intermediate Track (Month 4-6)

| Week | What To Do |
|---|---|
| 1-2 | `04_Data_Work/01-03`. EDA on a real dataset. |
| 3-4 | `04_Data_Work/04-09`. Master splits, leakage, imbalanced data. |
| 5-8 | `05_Machine_Learning/01-03`. Train 5 classical + 1 deep model. |
| 9-12 | `05_Machine_Learning/04-08` (whichever you need: CV/NLP/Time series). |

**Done when:** You can build a clean pipeline (load → preprocess → model → evaluate) on a new dataset in < 1 day.

---

## 🟠 Advanced Track (Month 7-9)

| Week | What To Do |
|---|---|
| 1-4 | `05_Machine_Learning/09-11`. Training pipelines, Optuna, reproducibility. |
| 5-8 | Run ablation studies. Beat SOTA on your chosen benchmark. |
| 9-12 | Start writing. `06_Paper_And_Publishing/01`. |

**Done when:** You have a strong-results table, an ablation table, a paper draft.

---

## 🔴 Publish Track (Month 10-12)

| Week | What To Do |
|---|---|
| 1-4 | Polish paper, get 3 friends to review it. |
| 5-6 | Submit to arXiv. Prepare conference submission. |
| 7-8 | Make a presentation + poster. `06_Paper_And_Publishing/06`. |
| 9-12 | Write thesis chapters from paper. Defend. |

**Done when:** You defended, paper on arXiv, code on GitHub. 🎓
