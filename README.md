# 📚 MSc Data Science Research

> **A simple, clean structure to learn research and complete your MSc thesis in Data Science.**

---

## 📁 7 Simple Folders

| # | Folder | What You'll Learn |
|---|---|---|
| 01 | `01_Research_Basics` | How research works |
| 02 | `02_Math_And_Stats` | Math you need |
| 03 | `03_Tools` | Python, Git, LaTeX |
| 04 | `04_Data_Work` | Data collection to features |
| 05 | `05_Machine_Learning` | ML & DL basics |
| 06 | `06_Paper_And_Publishing` | Write & publish papers |
| 07 | `07_My_Thesis` | Your actual MSc thesis |

---

## 🚀 How To Start

1. Start with `01_Research_Basics`
2. Read the .md file
3. Take notes
4. Move to next folder
5. Finally work on `07_My_Thesis`

---

## ⏱️ Time Needed

**Total: ~6-12 months** (2-3 hours/day)

| Folder | Time |
|---|---|
| 01_Research_Basics | 2 weeks |
| 02_Math_And_Stats | 4 weeks |
| 03_Tools | 2 weeks |
| 04_Data_Work | 3 weeks |

---

## 💡 Remember

- **Start small.** Don't try to learn everything at once.
- **Code every day.** Even 30 minutes counts.
- **Ask for help.** Email professors, join communities.
- **Stay consistent.** 2 hours daily > 14 hours on weekends.
- **Enjoy the journey.** You're becoming a researcher! 🎓
