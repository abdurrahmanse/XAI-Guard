## 📖 The End-to-End Story

If you only read **one** file: open **`RESEARCH_PROCESS.md`**. It walks through every stage of doing research in order, with both theory and code.

If you want a **checklist** to tick off as you go: open **`CHECKLISTS.md`**.

## ⏱️ Time Needed (if you're new)

**Total: ~6-12 months** (2-3 hours/day) for a full MSc thesis project.

| Stage | Folder | Time |
|---|---|---|
| 1. Learn research basics | `01_Research_Basics` | 2-4 weeks |
| 2. Build math foundation | `02_Math_And_Stats` | 4-6 weeks |
| 3. Set up tools | `03_Tools` | 1-2 weeks |
| 4. Master data work | `04_Data_Work` | 3-4 weeks |
| 5. Build ML models | `05_Machine_Learning` | 6-8 weeks |
| 6. Write & publish | `06_Paper_And_Publishing` | 4-8 weeks |
| 7. Run your thesis | `07_My_Thesis` | 4-8 months |

These overlap a lot. The 12-month path in `00_START_HERE/03_Learning_Roadmap.md` shows how.

## 🔁 Reusable For Every Project

Whenever you start a new research project:

```bash
cp -r 00_Project_Template/ ~/projects/my-new-project/
```

You get a ready-made structure: `data/`, `src/`, `notebooks/`, `experiments/`, `results/`, `configs/`, `docs/`, `references/`, `reports/`. Fill in the README and start.

## 💡 Remember

- **Start small.** Don't try to learn everything at once.
- **Code every day.** Even 30 minutes counts.
- **Read every week.** 1 paper per week > 50 papers at the end.
- **Ask for help.** Email professors, join communities, post on Stack Overflow.
- **Stay consistent.** 2 hours daily > 14 hours on weekends.
- **Reproduce, then extend.** Re-implement a paper before doing your own.
- **Document as you go.** Future you will thank present you.
- **Enjoy the journey.** You're becoming a researcher! 🎓
